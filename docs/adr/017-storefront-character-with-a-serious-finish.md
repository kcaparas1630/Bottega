# ADR 017 — Keep the storefront's character, give it a serious finish

- **Status:** Superseded by [ADR 018](018-experiment-neutral-professional-chrome.md)
- **Date:** 2026-11-01
- **Supersedes:** the awning, save-status, add-bar and app-rail lines of
  [ADR 016](016-professional-finish.md); its type and depth rules stay

## Context

ADR 016 removed the playful finish of [ADR 015](015-bodega-storefront-direction.md), but it also
removed the details people loved: the scalloped awning, the hang-tag aisles, the goods on the
counter, the sign hanging on the door and the mustard tab. What read as cartoony was the
execution — tilts, pushpins, thick ink outlines, hard offset shadows, wonky letters — not the
objects themselves.

## Decision

Bring the objects back, built with ADR 016's restraint:

| Object               | Serious finish                                                                                        |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| Scalloped awning     | Brick-red and cream stripes with small, shallow scallops and a soft shadow; no ink rail               |
| Hang-tag aisles      | Upright cream tags on thin strings, punched hole, small caps; current aisle in mustard; soft shadow   |
| Counter goods        | Drawn prints, letter tiles and paper shapes standing upright, soft shadows, small-caps labels         |
| Door sign            | A cream enamel sign hung on two strings from a nail; "OPEN" in letter-spaced serif capitals; no swing |
| Active inspector tab | Mustard fill with a hairline edge                                                                     |

Still ruled out: rotations, pushpins, 2px ink outlines, hard offset shadows, Fraunces' soft and
wonky letterforms in the interface, and bounce or swing.

## Consequences

- Each object keeps one signature detail (scallop, punched hole, string, upright goods) and drops
  everything else that made it a toy.
- Future surfaces follow the same test: a real shop object, finished like a print house would.
